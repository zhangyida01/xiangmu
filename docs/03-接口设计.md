# 接口设计（REST API）

> 配套：docs/01-功能清单与需求说明.md、docs/02-数据库设计.md
> 基础路径：`/api`，全部为 JSON（文件上传下载除外）
> 鉴权：登录后返回 JWT，后续请求带 `Authorization: Bearer <token>`
> 接口文档：集成 SpringDoc OpenAPI，开发期访问 `/swagger-ui.html`

## 一、通用约定

### 1.1 统一响应结构

```json
{ "code": 0, "msg": "ok", "data": {}, "traceId": "9f2c1a" }
```

| code | 含义 |
| --- | --- |
| 0 | 成功 |
| 40001 | 参数校验失败 |
| 40101 | 未登录或 Token 失效 |
| 40301 | 无权限（角色或敏感能力不足） |
| 40302 | 二次密码校验失败 |
| 40401 | 资源不存在 |
| 40901 | 业务冲突（如项目编号重复、归档后禁止修改） |
| 42301 | 账号被锁定 |
| 50001 | 服务器内部错误 |

### 1.2 分页约定

请求参数：`page`（从 1 开始）、`size`（默认 20，最大 200）、`sort`（如 `create_time,desc`）。

响应：

```json
{ "code": 0, "data": { "total": 128, "page": 1, "size": 20, "records": [] } }
```

### 1.3 权限注解约定

后端每个接口标注所需权限，前端按登录返回的 `permissions` 集合控制菜单与按钮：

| 标识 | 说明 |
| --- | --- |
| `ROLE_ADMIN` / `ROLE_USER` / `ROLE_VIEWER` | 角色 |
| `secret:view` | 查看凭据明文 |
| `secret:export` | 导出凭据 |
| `file:download` | 下载附件 |
| `project:delete` | 删除项目 |
| `system:manage` | 系统管理（用户、参数、字典） |
| `audit:view` | 查看审计日志 |

默认映射：ADMIN 拥有全部；USER 拥有 `secret:view`、`file:download`；VIEWER 只有只读接口。可在用户管理里单独调整 `secret:view`、`secret:export`、`file:download`、`project:delete`。

### 6.1 reveal 接口示例

请求：

```json
POST /api/credentials/12/reveal
{ "recheckToken": "eyJ..." }
```

响应：

```json
{
  "code": 0,
  "data": {
    "id": 12,
    "username": "admin",
    "secret": "P@ssw0rd-Real",
    "secretType": "PASSWORD",
    "autoHideSec": 60,
    "clipboardClearSec": 30,
    "accessId": 8891
  }
}
```

失败场景：无 `secret:view` 返回 40301；开启二次确认但未带或带错 recheckToken 返回 40302；两种失败都写审计（success=0）。

## 九、错误与幂等约定

- 写操作（POST/PUT）建议前端带 `X-Request-Id`，后端对创建类接口做去重（同一 Request-Id 5 秒内重复提交直接返回上次结果），避免网络重试导致重复建档。
- 所有业务异常统一由全局异常处理器转成第 1.1 节的响应结构，不返回堆栈。
- 文件下载失败（文件丢失）返回 40401 并在响应头 `X-File-Missing: 1`，前端提示"文件已丢失，请检查备份"。
- 请求体大小限制与 Nginx `client_max_body_size` 需同步配置，默认 512m。
